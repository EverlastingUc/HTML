# HTML Practice Exercises and Projects

Try each task yourself before looking up an answer. Save projects as `.html` files and open them in a browser.

## Level 1 — Foundations

- [ ] Create a valid `index.html` document.
- [ ] Set the title to your name.
- [ ] Add an `h1`, two `h2` headings and three paragraphs.
- [ ] Use `strong` and `em` correctly.
- [ ] Add an HTML comment.
- [ ] Create a nested list of favorite subjects.

## Level 2 — Content and navigation

- [ ] Link to five favorite websites.
- [ ] Create `about.html` and link to it from the home page.
- [ ] Add an image with meaningful alt text.
- [ ] Create an ordered instruction list.
- [ ] Define HTML, CSS and JavaScript in a description list.
- [ ] Build a table with caption, headers and three data rows.

## Level 3 — Forms

- [ ] Create a contact form with name, email and message.
- [ ] Connect every control to a visible label.
- [ ] Make email required.
- [ ] Add radio buttons for a preferred contact method.
- [ ] Add independent checkboxes for interests.
- [ ] Add a select menu and submit button.
- [ ] Group related controls with fieldset and legend.

## Level 4 — Semantic HTML

- [ ] Build a page with header, nav, main, article and footer.
- [ ] Add a section with a meaningful heading.
- [ ] Add an aside for related information.
- [ ] Replace generic divs with semantic elements where appropriate.
- [ ] Check the heading outline without relying on visual styling.

## Level 5 — Media and modern features

- [ ] Add an audio player with controls.
- [ ] Add a video with captions.
- [ ] Add a responsive image using picture or srcset.
- [ ] Create an FAQ with details and summary.
- [ ] Add a progress indicator.
- [ ] Create a dialog and learn how JavaScript opens it.
- [ ] Add an inline SVG with an accessible title.

## Mini-projects

### 1. Personal profile page
Include a title, main heading, profile image with alt text, about section, interests list, project links and contact section.

### 2. Recipe page
Include a recipe title, description, image, ingredients list, ordered instructions, preparation time and (if relevant) a nutrition table.

### 3. Student registration form
Include name, email, date of birth, phone, course selection, radio group, interest checkboxes, required fields and submit button. A real registration system needs a server endpoint; static HTML alone does not save registrations.

### 4. Multi-page learning website
Create `index.html`, `about.html`, `lessons.html` and `contact.html`. Add shared navigation and consistent semantic structure.

### 5. Accessible article
Include document language and metadata, logical headings, descriptive links, suitable image alternatives, a quotation and code sample. Test keyboard access.

## Self-review checklist

- [ ] I can explain what HTML stands for.
- [ ] I know the difference between a tag and an element.
- [ ] I can write a complete document from memory.
- [ ] I understand attributes and boolean attributes.
- [ ] I know common void elements.
- [ ] I can create links and images using correct paths.
- [ ] I can build lists and data tables.
- [ ] I can create a labelled form.
- [ ] I understand semantic page structure.
- [ ] I know why alt text and keyboard access matter.
- [ ] I can use developer tools and an HTML validator.
- [ ] I understand the roles of HTML, CSS and JavaScript.

## Check your work

1. Open the file in a browser.
2. Test every link and form control.
3. Navigate using Tab, Shift+Tab, Enter and Space.
4. Inspect the page with browser developer tools.
5. Validate it with the [Nu HTML Checker](https://validator.w3.org/nu/).
6. Fix issues and repeat.

Finishing these exercises means you have practiced the foundations. Keep consulting the official references because HTML is a broad, evolving standard.
