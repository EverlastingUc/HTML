What is HTML?

HTML means HyperText Markup Language. It describes the structure and meaning of web content.

Read the MDN HTML reference.

Topics to learn

  • Document structure
  • Text and headings
  • Links and images
  • Lists and tables
  • Forms and semantic HTML

Learning order

  1. Understand elements and attributes.
  2. Build a simple page.
  3. Add links, images and lists.
  4. Practice forms and semantic structure.
